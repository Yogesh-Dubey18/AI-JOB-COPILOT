# Final Acceptance Criteria

## Local Product

- App builds locally.
- Backend tests pass.
- Frontend tests pass.
- Core pages render.
- Mock AI fallback works.
- Resume/job/application/interview workflows are represented.

## Repository

- No secrets tracked.
- No generated artifacts tracked.
- README is honest.
- Docs index is current.
- Changelog exists.
- Handover docs exist.

## Deployment Readiness

- Env examples are placeholder-only.
- Deployment runbooks exist.
- Production checklist exists.
- Live URL docs use placeholders until real URLs are provided.

## User Safety

- No auto-apply.
- No fake experience generation.
- No unsafe scraping.
- Application messages are user-reviewed.
