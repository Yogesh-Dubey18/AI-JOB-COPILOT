## LinkedIn Post Draft

I built AI Job Copilot, a full-stack AI-powered job-search SaaS project for job seekers.

It helps candidates upload a resume, analyze ATS readiness, review matching jobs, generate user-reviewed application materials, track applications, prepare for interviews, analyze rejections, and monitor their job-search journey.

Tech stack:
- Next.js, React, TypeScript, Tailwind CSS
- Node.js, Express.js, TypeScript
- MongoDB/Mongoose-ready architecture
- JWT auth
- Mock AI fallback with OpenAI/Gemini provider-ready structure
- Vitest/Supertest tests
- Deployment and security runbooks

Important note: this project does not auto-apply to jobs or auto-send recruiter messages. Application content stays user-reviewed.
