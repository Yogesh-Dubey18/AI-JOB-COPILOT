# Final Production Launch Checklist

## Before Launch

- MongoDB Atlas configured.
- Backend deployed.
- Frontend deployed.
- `CLIENT_URL` points to frontend URL.
- `NEXT_PUBLIC_API_URL` points to backend `/api`.
- JWT secrets are strong and server-only.
- Backend health endpoint passes.
- Root build/test passes locally.
- Git safety passes.
- Docs link check passes.

## Smoke Test

- Open landing page.
- Register a test account.
- Log in.
- Complete onboarding.
- Upload a small test resume.
- Run resume analysis.
- View jobs.
- Match a job.
- Create application.
- Generate interview prep.
- View analytics.

## After Launch

- Record real URLs only after verification.
- Monitor errors and uptime.
- Collect feedback.
- Create issues for fixes.
