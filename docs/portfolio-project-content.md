# Portfolio Project Content

## Title

AI Job Copilot

## Subtitle

Full-stack AI SaaS for job seekers.

## Description

AI Job Copilot helps candidates manage the job-search journey from resume upload to interview prep. It includes ATS analysis, job matching, tailored resumes, application kit generation, application tracker, interview preparation, analytics, notifications, admin, and deployment docs.

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Express.js
- MongoDB/Mongoose
- JWT auth
- Zod
- TanStack Query
- Recharts
- OpenAI/Gemini-ready AI provider architecture

## Highlights

- Complete job-seeker SaaS workflow.
- Safe AI mock fallback.
- User-reviewed application messages.
- Deployment-ready docs.
- Tests and Git safety checks.

## Limitations

- No live URL yet.
- Billing and email are mock/provider-ready.
- PDF/DOCX parsing can be improved.
