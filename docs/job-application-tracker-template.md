# Job Application Tracker Template

Use this template in the app tracker, a spreadsheet, or the docs while running a manual campaign.

## Table Columns

| Date | Company | Role | Source | Location | Job URL | Resume Version | Match Score | Status | Follow-Up Date | Notes |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| YYYY-MM-DD | Company name | Role title | LinkedIn/company site/referral | Remote/city | Official link | Resume v1/v2 | 0-100 | Saved/Applied/HR Call/etc. | YYYY-MM-DD | Key context |

## Status Values

- Saved
- Applied
- Resume Viewed
- HR Call
- Assignment
- Technical Round 1
- Technical Round 2
- Managerial Round
- HR Round
- Offer
- Selected
- Rejected
- Withdrawn

## Minimum Entry

Every application should have:

- Official job URL or source.
- Resume version used.
- Application date.
- Current status.
- Follow-up date if no response is expected within 5 to 7 days.
- Notes about requirements, recruiter name, or interview topics.

## Weekly Metrics

- Applications sent.
- Replies received.
- Shortlists.
- Interviews scheduled.
- Rejections.
- Offers.
- Best performing job source.
- Best performing resume version.
