# Recruiter Demo Script

## Opening

AI Job Copilot is a full-stack SaaS project I built for job seekers. It helps a candidate upload a resume, understand ATS readiness, find matching jobs, tailor application materials, track applications, prepare for interviews, and improve after feedback.

## Demo Flow

1. Show the landing page and explain the job-seeker focus.
2. Register or log in with a demo account.
3. Open the dashboard and show career health, jobs, applications, and interview signals.
4. Upload a safe sample resume.
5. Run resume analysis and explain ATS factors.
6. Open jobs and show match score, missing skills, and trust signals.
7. Tailor a resume and generate an application kit.
8. Track the application and follow-up date.
9. Open interview coach and analytics.
10. Show admin feedback triage and system health.

## Technical Close

The stack is Next.js, TypeScript, Tailwind, Express, MongoDB/Mongoose, JWT auth, mock/provider-ready AI, tests, CI docs, PWA foundation, extension foundation, and deployment runbooks.

## Honest Close

The app is production-oriented and locally verified, but live deployment, real provider credentials, and legal/commercial review are manual next steps.
