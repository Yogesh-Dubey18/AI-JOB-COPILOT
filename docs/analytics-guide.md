# Analytics Guide

Analytics help job seekers understand whether their job-search process is improving.

## Current Metrics

- Saved jobs.
- Applied jobs.
- Shortlisted count.
- Interview count.
- Rejections.
- Offers.
- Response rate.
- Interview rate.
- Offer rate.
- Average ATS score.
- Resume score trend.
- Missing skills.
- Application status distribution.

## Interpretation

- Low response rate: improve targeting, resume keywords, and apply quality.
- Low interview rate: strengthen project proof and application messages.
- High rejection rate after interviews: practice project explanation and core topics.
- Repeated missing skills: create a 7-day and 30-day learning sprint.

## Future Work

- Source-level conversion.
- Resume-version performance.
- Message A/B testing.
- Job-search health score.
- Cohort analytics for product decisions.
