# User Guide

AI Job Copilot helps job seekers run a structured application process.

## Daily Workflow

1. Review dashboard suggestions.
2. Check daily matching jobs.
3. Open high-match job details.
4. Review missing skills and scam risk.
5. Tailor resume without adding fake experience.
6. Generate application messages.
7. Apply manually through the official link.
8. Track the application and follow-up date.
9. Prepare for interviews.
10. Record result and improve after rejection.

## Safe AI Usage

- Review every generated resume and message.
- Do not add skills or experience you cannot explain.
- Do not auto-send recruiter messages.
- Use rejection analysis as guidance, not certainty.

## Best Results

- Keep profile skills current.
- Upload a clean text-selectable resume.
- Maintain one resume version per target role.
- Track every application stage.
- Practice interview answers using your real projects.
