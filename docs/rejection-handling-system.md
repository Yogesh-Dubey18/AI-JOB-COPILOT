# Rejection Handling System

Rejection is data. Record it, learn from it, and adjust the next batch.

## Immediate Response

- Update application status to Rejected.
- Record the rejection date.
- Add the stated reason if provided.
- Do not argue with the recruiter.
- Send a polite closing note if the process involved interviews.

## Analysis Prompts

- Was the role too senior?
- Was the resume weak for the role?
- Were required skills missing?
- Did the interview expose a technical gap?
- Was the assignment incomplete or unclear?
- Was there a location, salary, or notice-period mismatch?

## Improvement Plan

- Update one resume bullet.
- Practice one weak technical topic.
- Improve one project README or demo.
- Add one missing keyword only if it is truthful.
- Adjust role filters if too many roles are unrealistic.

## Rejection Follow-Up Message

Hi [Name], thank you for letting me know. I appreciate the opportunity to interview/apply for [Role]. If possible, I would be grateful for any brief feedback that can help me improve. I hope we can stay connected for future opportunities.
