# Mock Interview Scoring Guide

AI Job Copilot scores mock interview answers to help users improve clarity and preparation. The scoring is advisory and should never be treated as a hiring guarantee.

## Score Dimensions

| Dimension | Meaning |
| --- | --- |
| Confidence | Clear, calm, direct delivery. |
| Technical accuracy | Correct concepts, APIs, architecture, and tradeoffs. |
| Communication | Structured answer, not rambling. |
| Completeness | Covers the question with enough context and result. |
| Project clarity | Explains the user's actual project contribution and decisions. |

Scores are currently 1 to 10 for each dimension. The UI displays them as progress bars.

## Strong Answer Pattern

Use:

1. Situation or problem.
2. Your exact responsibility.
3. Technical approach.
4. Tradeoff or challenge.
5. Result or learning.

## Project Answer Checklist

- Project is real.
- User can explain architecture.
- User can identify their own contribution.
- User can discuss one technical challenge.
- User can explain what they would improve.

## HR Answer Checklist

- Answer is short enough.
- Example is specific.
- Tone is honest and positive.
- No fake claims.
- Connects back to the role.

## DSA Answer Checklist

- Restates problem.
- Explains brute force briefly if useful.
- Gives optimized approach.
- Mentions time and space complexity.
- Tests edge cases.

## Interpreting Scores

- 8-10: strong, keep practicing for consistency.
- 6-7: usable but needs sharper examples or technical clarity.
- 4-5: answer likely needs restructuring.
- 1-3: revisit fundamentals and practice with simpler examples.

## Product Notes

Mock scoring uses provider-ready AI with mock fallback. If no AI key is configured, the app still returns structured feedback so local demos and tests remain usable.
