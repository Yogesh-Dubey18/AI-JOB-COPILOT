# Full-Stack Mastery Checklist

Use this checklist to become confident enough to build, debug, and explain production-style web apps.

## Frontend

- [ ] Build responsive layouts without text overlap.
- [ ] Use forms with validation and accessible errors.
- [ ] Handle loading, empty, and error states.
- [ ] Use API clients safely with clear failure behavior.
- [ ] Write component/page tests for common flows.
- [ ] Explain client/server component choices.

## Backend

- [ ] Design routes, controllers, services, and models cleanly.
- [ ] Validate inputs before database writes.
- [ ] Add auth middleware and role checks.
- [ ] Use indexes and pagination for growing data.
- [ ] Return safe errors without leaking internals.
- [ ] Write API tests for critical flows.

## Database

- [ ] Model users, profiles, resumes, jobs, applications, interviews, and AI requests.
- [ ] Add indexes for common queries.
- [ ] Keep user data isolated.
- [ ] Avoid storing secrets in documents.
- [ ] Plan backup and migration strategy before production.

## Product Engineering

- [ ] Understand the user journey end to end.
- [ ] Keep AI outputs user-review based.
- [ ] Label mock/provider-ready features honestly.
- [ ] Document deployment and support tasks.
- [ ] Convert feedback into issues.
