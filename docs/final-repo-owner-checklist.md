# Final Repo Owner Checklist

This checklist is for the repository owner after Phase 50.

## Before Sharing Publicly

- [ ] Run full local verification.
- [ ] Confirm GitHub repository is public or private by choice.
- [ ] Confirm no secrets or generated artifacts are tracked.
- [ ] Confirm README does not claim live deployment unless URLs are real.
- [ ] Confirm screenshots or demo videos do not expose local secrets.
- [ ] Confirm license choice or license note is intentional.

## Before Deploying

- [ ] Create MongoDB Atlas cluster.
- [ ] Create backend service.
- [ ] Create frontend project.
- [ ] Add provider secrets through dashboards only.
- [ ] Configure CORS.
- [ ] Run smoke tests.
- [ ] Update live URL docs only after verification.

## Before Commercial Use

- [ ] Complete professional legal review.
- [ ] Complete privacy and data retention review.
- [ ] Configure billing and tax flow.
- [ ] Configure support process.
- [ ] Configure incident response process.
- [ ] Configure monitoring and alerting.
- [ ] Validate AI and resume handling privacy.

## Before Job Applications

- [ ] Update resume with honest project bullets.
- [ ] Update LinkedIn and GitHub profile.
- [ ] Pin the repository.
- [ ] Prepare role-specific resume versions.
- [ ] Use manual job application review.
- [ ] Track outcomes and feedback.

## Ongoing Maintenance

- [ ] Use issues for new work.
- [ ] Keep changes small and verified.
- [ ] Update CHANGELOG for meaningful changes.
- [ ] Keep docs links valid.
- [ ] Re-run git safety before every commit.
