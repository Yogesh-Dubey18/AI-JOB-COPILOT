# v2 Career Project Alignment Plan

Use this plan to choose v2 work that helps both the product and your job search.

## High-Value Alignment Areas

| v2 Area | Career Value | Demo Value |
| --- | --- | --- |
| Resume parsing and ATS | Shows backend, AI, and product thinking | Strong job seeker workflow |
| Application tracker intelligence | Shows CRM-style product logic | Clear daily-use feature |
| Notification and email foundation | Shows architecture and provider boundaries | Practical follow-up reminders |
| AI provider safety | Shows AI engineering maturity | Trustworthy mock/provider-ready behavior |
| Admin operations and audit logs | Shows SaaS thinking | Strong technical interview topic |
| Privacy export/delete | Shows responsible data handling | Recruiter-friendly production awareness |
| PDF exports | Shows user-facing polish | Concrete output users understand |

## Selection Rule

Choose v2 work that satisfies at least two of these:

- Improves a real user workflow.
- Strengthens an interview topic.
- Can be tested locally.
- Does not require real external credentials.
- Can be shown honestly in a demo.

## Quarterly Focus

- Quarter 1: Resume intelligence, job matching, and application tracker.
- Quarter 2: AI quality, notifications, and privacy.
- Quarter 3: public portfolio, exports, and extension/PWA.
- Quarter 4: analytics, monitoring, stabilization, and case study.
