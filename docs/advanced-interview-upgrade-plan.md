# Advanced Interview Upgrade Plan

This plan is for moving from basic interview readiness to confident technical discussion.

## Project Deep Dive

- Explain the problem AI Job Copilot solves.
- Walk through user journey, frontend, backend, database, AI provider fallback, and deployment plan.
- Explain why auto-apply is intentionally not implemented.
- Explain limitations honestly.

## Technical Upgrade Areas

- Auth flow with refresh tokens and httpOnly cookies.
- MongoDB model relationships and indexes.
- API validation and safe error handling.
- AI prompt/schema architecture.
- Testing strategy and gaps.
- Deployment environment variables and CORS.

## Practice Format

1. Pick one topic.
2. Explain it in 2 minutes.
3. Draw the data flow.
4. Answer likely follow-up questions.
5. Write down weak points.

## Weekly Mock Questions

- How would you scale job matching for many users?
- How would you reduce AI API cost?
- How would you protect resume data?
- How would you debug a production CORS issue?
- How would you test the application tracker?
