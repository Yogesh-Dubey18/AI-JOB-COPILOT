# Weekly Job Sprint Plan

This sprint is designed for freshers and entry-level developers who need consistent applications without sacrificing quality.

## Monday: Setup And Targeting

- Choose 2 priority roles for the week.
- Update resume keywords for those roles.
- Review dashboard analytics and missing skills.
- Prepare message templates for recruiters and referrals.

## Tuesday: Application Batch 1

- Apply to 8 to 10 high-fit jobs.
- Tailor resume for each strong match.
- Save all entries in the tracker.
- Send 5 recruiter messages.

## Wednesday: Outreach And Skill Work

- Send 5 to 8 referral requests.
- Improve one portfolio project section.
- Practice interview questions for the current role.
- Follow up on applications older than 5 business days.

## Thursday: Application Batch 2

- Apply to 8 to 10 more roles.
- Compare response quality by job source.
- Record scam or low-trust patterns.

## Friday: Review And Interview Prep

- Review all statuses.
- Update rejection reasons and AI improvement plans.
- Do one mock interview.
- Prepare the next week's focus.

## Weekend: Deep Work

- Improve a project, GitHub README, portfolio page, or technical explanation.
- Refresh LinkedIn profile if the role target changed.
- Clean stale saved jobs.
