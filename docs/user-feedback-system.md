# User Feedback System

Feedback should become issues, not disappear into chat messages.

## Feedback Types

- Bug.
- Confusing UI.
- Missing feature.
- AI quality issue.
- Resume parsing issue.
- Job matching quality issue.
- Interview prep quality issue.
- Documentation issue.

## Feedback Fields

- User role.
- Page or feature.
- Expected behavior.
- Actual behavior.
- Screenshot or steps if available.
- Severity.
- Consent to follow up.

## Workflow

1. Collect feedback through a form, email, or support channel.
2. Remove personal data before sharing.
3. Convert actionable feedback into a GitHub issue.
4. Label by area and severity.
5. Prioritize during weekly review.
6. Close the loop with the user when fixed.
