# Developer Habits Checklist

Small habits compound faster than huge one-time efforts.

## Daily

- [ ] Write code or read code for at least one focused block.
- [ ] Run the relevant build/test command after meaningful changes.
- [ ] Update notes for any bug, interview question, or learning gap.
- [ ] Apply to jobs manually and track quality, not only quantity.

## Weekly

- [ ] Clean one part of the project or docs.
- [ ] Practice one DSA topic.
- [ ] Explain one feature out loud.
- [ ] Review application and interview metrics.
- [ ] Update GitHub/LinkedIn only with real progress.

## Before Pushing Work

- [ ] No secrets.
- [ ] No build output.
- [ ] No generated PDFs.
- [ ] Tests/build attempted.
- [ ] Commit message explains the change.

## Before Interviews

- [ ] Project story is ready.
- [ ] Resume matches real skills.
- [ ] Demo fallback plan is ready.
- [ ] Questions for interviewer are ready.
