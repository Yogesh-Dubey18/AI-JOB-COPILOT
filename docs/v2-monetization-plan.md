# v2 Monetization Plan

This is a planning document, not a claim of live revenue.

## Plans

- Free: resume upload, basic ATS score, limited job matches, application tracker.
- Pro: unlimited tailoring, application kits, interview prep, daily digest.
- Premium: mock interviews, portfolio generator, advanced mentor, deeper analytics.

## Billing Architecture

- Mock provider first.
- Stripe-ready service interface.
- Usage event tracking.
- Plan limit helper/middleware.
- Upgrade prompts in frontend.

## Pricing Validation

- Test willingness to pay with real users before charging.
- Do not overpromise job placement.
- Make cancellation and refund policies clear.
