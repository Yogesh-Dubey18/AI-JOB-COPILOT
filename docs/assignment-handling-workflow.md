# Assignment Handling Workflow

Use this workflow for take-home assignments.

## Before Starting

- Confirm deadline.
- Confirm expected tech stack.
- Ask clarifying questions if requirements are unclear.
- Estimate scope honestly.
- Create a small checklist.

## During Build

- Keep commits clean.
- Prioritize required features first.
- Add validation and error handling.
- Test the main flow.
- Write a clear README.

## Before Submission

- Run build and tests.
- Check screenshots or local demo.
- Remove secrets and build artifacts.
- Confirm `.env.example` is placeholder-only.
- Add known limitations.

## After Submission

- Send a concise email.
- Log the assignment in the tracker.
- Schedule follow-up.
- Prepare to explain tradeoffs.
