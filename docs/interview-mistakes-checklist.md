# Interview Mistakes Checklist

## Avoid

- Claiming fake experience.
- Saying you know tools you cannot explain.
- Giving very long unstructured answers.
- Not asking clarifying questions.
- Ignoring edge cases in coding.
- Not knowing your own project.
- Blaming previous rejections.
- Asking salary before role discussion unless prompted.

## Fix

- Use structured answers.
- Keep examples real.
- Practice project explanation.
- Admit gaps and explain learning plan.
