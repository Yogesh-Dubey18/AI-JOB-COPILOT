# Support Operations Guide

## Channels

- In-app feedback for product issues.
- Support inbox to be configured before public launch.
- GitHub issues for public technical backlog only after privacy review.

## Categories

- Account access.
- Billing question.
- Resume upload or analysis issue.
- Job matching issue.
- Application tracker issue.
- Privacy or deletion request.
- Security concern.
- Product feedback.

## Response Targets

These are draft internal targets, not public SLA promises:

- Security/privacy: same business day review.
- Billing: one to two business days.
- Core workflow blocker: one business day.
- General product feedback: weekly triage.

## Escalation

- Security/privacy issues go to the incident response process.
- Billing issues require payment-provider dashboard access.
- Legal requests require professional review.
- Data deletion issues require privacy workflow verification.
