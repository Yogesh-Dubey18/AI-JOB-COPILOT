# Common Fresher Workplace Mistakes

- Not asking questions when blocked.
- Asking before trying anything.
- Not reading error messages.
- Making large unfocused PRs.
- Ignoring code review feedback.
- Not testing changes.
- Poor status updates.
- Overpromising timelines.
- Hiding mistakes.
- Not documenting learning.

## Better Pattern

Try, document, ask clearly, update regularly, and learn from feedback.
