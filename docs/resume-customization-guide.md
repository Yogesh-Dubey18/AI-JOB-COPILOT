# Resume Customization Guide

Customize the resume for the role without inventing experience.

## What To Change

- Target headline.
- Professional summary.
- Skill ordering.
- Project bullet ordering.
- Keywords already supported by real work.
- Relevant coursework or certifications.

## What Not To Change

- Do not add companies, internships, or employment history that did not happen.
- Do not add tools you cannot discuss.
- Do not copy the full job description into the resume.
- Do not hide gaps with false claims.

## Role-Based Focus

React roles:
- Lead with React, TypeScript, UI state, forms, API integration, responsive design.

MERN roles:
- Lead with React, Node.js, Express, MongoDB, REST APIs, auth, deployment readiness.

Backend roles:
- Lead with Express, API design, MongoDB, validation, auth, error handling, tests.

Java roles:
- Lead with Java, OOP, DSA, backend fundamentals, problem solving.
