# Joining Preparation Plan

## Before Joining

- Review offer and joining date.
- Complete documents.
- Revise core tech stack.
- Review Git basics.
- Practice communication.
- Prepare introduction.

## First Week

- Understand team structure.
- Set up development environment.
- Read onboarding docs.
- Ask questions respectfully.
- Take notes.
- Do not rush risky changes.

## First Month

- Understand codebase.
- Pick small tasks.
- Ask for feedback.
- Improve debugging.
- Communicate blockers early.
