# Resume Export Guide

Use this guide when exporting resumes and career assets from AI Job Copilot.

## Resume Export Workflow

1. Upload or generate a resume.
2. Review the parsed content and ATS score.
3. Tailor the resume only with truthful skills, projects, and experience.
4. Generate a PDF or DOCX export from the Exports page (`/pdf-export`).
5. Open the exported file and review formatting before sharing.
6. Rename the file using the naming convention: `CandidateName_TargetRole_Resume.pdf` or `.docx`.

## Export Types

| Type | Route | Format |
|------|-------|--------|
| Resume | `POST /api/exports/resume/:id` | PDF |
| Resume | `POST /api/exports/resume-docx/:id` | DOCX |
| Tailored resume | `POST /api/exports/tailored-resume/:id` | PDF |
| Application kit | `POST /api/exports/application-kit/:id` | PDF |
| Portfolio | `POST /api/exports/portfolio/:id` | PDF |
| Interview prep | `POST /api/exports/interview-prep/:id` | PDF |

## File Naming Convention

Rename your exported file before sending:
- `YogeshDubey_BackendDeveloper_Resume.pdf`
- `YogeshDubey_ReactDeveloper_Resume.docx`
- `YogeshDubey_NodeJS_ApplicationKit.pdf`

This helps recruiters identify the file easily and improves professionalism.

## Export Quality Checklist

- [ ] Contact details are correct.
- [ ] Skills are true and can be explained in interview.
- [ ] Project bullets match actual work done.
- [ ] No fake experience, certifications, or employers added.
- [ ] Portfolio visibility settings reviewed.
- [ ] PDF/DOCX opens correctly before sharing.
- [ ] File renamed to `CandidateName_Role_Resume.pdf` format.
- [ ] Official job application is manual and user-reviewed.

## Generated File Safety

- Exports are generated by the backend renderer on demand.
- **No generated PDFs/DOCX files are committed to git** (covered by `.gitignore`).
- Files stored locally in development; move to object storage (S3/R2) in production.
- Signed download URLs should be used in production to prevent direct URL sharing.

## Production Upgrade Path

The v2 renderer creates reliable basic PDFs. For commercial polish:

- Add branded resume template (Helvetica, Inter, or custom fonts).
- Add page headers and footers.
- Add ATS-friendly one-page layout constraints.
- Add preview-before-export step in the UI.
- Store files in S3/R2 with signed download URLs.
- Add scheduled cleanup for old exported files.
- Add DOCX template with styles for headings, bullets, and contact section.

## Honesty Rules

AI Job Copilot must never add fabricated experience, education, certifications, job titles, employers, or projects. Exports are packaging for reviewed, user-approved data — not a tool to invent credentials.
