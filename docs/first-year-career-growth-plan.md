# First Year Career Growth Plan

## Months 1-3

- Learn team stack.
- Build debugging habits.
- Make small reliable contributions.
- Improve communication.

## Months 4-6

- Own small features.
- Improve testing.
- Understand product domain.
- Start mentoring through docs or notes.

## Months 7-9

- Take larger tasks.
- Improve architecture understanding.
- Learn performance and security basics.

## Months 10-12

- Lead a small feature area.
- Improve system design basics.
- Prepare for next career level.
