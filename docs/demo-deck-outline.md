# Demo Deck Outline

## 1. Title

AI Job Copilot: AI-powered career operating system for job seekers.

## 2. Problem

Job seekers manage too many disconnected tasks with too little feedback.

## 3. User Journey

Upload resume, analyze, match jobs, tailor resume, generate application kit, track application, prepare interviews, improve after rejection.

## 4. Product Screens

- Dashboard.
- Resume analyzer.
- Jobs and job detail.
- Tailor resume.
- Application tracker.
- Interview coach.
- Analytics.
- Admin feedback.

## 5. Architecture

Next.js, Express, MongoDB-ready repository, AI provider abstraction, tests, docs, CI/CD readiness.

## 6. Safety

No auto-apply, no auto-send, no invented experience, mock provider fallback, privacy export/delete, feedback review.

## 7. Demo Close

Production-oriented portfolio project with clear manual launch gates.
