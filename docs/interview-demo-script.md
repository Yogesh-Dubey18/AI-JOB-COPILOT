# Interview Demo Script

## 60-Second Pitch

AI Job Copilot is a full-stack AI SaaS for job seekers. It lets a candidate upload a resume, analyze ATS score, find matching jobs, tailor a resume, generate application messages, track applications, prepare for interviews, and review analytics.

## Demo Path

1. Show landing page.
2. Open dashboard.
3. Upload or select resume.
4. Run ATS analysis.
5. Open jobs and job detail.
6. Generate match and tailored resume.
7. Generate application kit.
8. Track an application.
9. Open interview prep and analytics.
10. Show admin and deployment docs.

## Architecture Talking Points

- Next.js frontend.
- Express backend.
- MongoDB/Mongoose.
- JWT auth.
- AI provider fallback.
- Mock billing/email/provider architecture.
- Git safety and deployment runbooks.
