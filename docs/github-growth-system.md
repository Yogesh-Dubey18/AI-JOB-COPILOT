# GitHub Growth System

The goal is to show consistent, honest engineering progress.

## Weekly GitHub Routine

- Close or update at least one issue.
- Keep commits focused and explainable.
- Update documentation when behavior changes.
- Avoid committing generated files, secrets, local env files, or dependency folders.
- Keep README current with setup, verification, and limitations.

## Repository Presentation

- Pin AI Job Copilot only after the README is clean and build/test commands pass locally.
- Use screenshots only if they are current and not misleading.
- Add a case study link when available.
- Keep live URLs as placeholders until real deployment is complete.

## Avoid

- Fake stars, users, customers, or production metrics.
- Large unfocused commits.
- README claims that the code cannot support.
- Real secrets in examples or screenshots.
