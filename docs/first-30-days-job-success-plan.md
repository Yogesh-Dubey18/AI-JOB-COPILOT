# First 30 Days Job Success Plan

## Days 1-7

- Setup tools.
- Meet team.
- Read docs.
- Understand product.
- Shadow tasks.

## Days 8-15

- Fix small bugs.
- Write notes.
- Ask for code review feedback.
- Learn team conventions.

## Days 16-30

- Own a small feature or bug.
- Improve test/debug habits.
- Document what you learn.
- Ask for feedback meeting.

## Success Signals

- Reliable communication.
- Clean small PRs.
- Honest blocker updates.
- Learning from feedback.
