# Maintainer Checklist

## Weekly

- Review Git status.
- Run verification commands.
- Review open issues.
- Update product backlog.
- Review docs for outdated links.

## Before Release

- Run full build/test.
- Run git safety and docs checks.
- Update changelog.
- Update known limitations.
- Verify no generated artifacts are staged.
- Confirm deployment env docs are current.

## Before Public Demo

- Confirm frontend and backend live URLs if available.
- Confirm backend health.
- Confirm API URL config.
- Confirm mock/provider limitations are disclosed.
- Prepare demo account only if safe.

## After Feedback

- Remove private data from reports.
- Convert issues into backlog items.
- Add regression tests for bugs.
