# Regression Test Checklist

Run this before demo, deployment, or release tags.

## Auth

- Register.
- Login.
- Logout.
- Refresh/me route.
- Protected dashboard access.

## Resume

- Upload supported file.
- View parsed preview.
- Analyze resume with mock fallback.
- View ATS score and suggestions.

## Jobs

- List jobs.
- Filter/search jobs.
- Open job detail.
- Match job.
- Tailor resume.

## Applications

- Create application.
- Update status.
- Add notes.
- View detail page.

## Interviews And AI

- Generate interview prep.
- Run mock interview answer flow.
- Generate skill gap plan.
- Run scam detector.

## Admin And Analytics

- View analytics dashboard.
- View admin dashboard.
- View AI usage page.
