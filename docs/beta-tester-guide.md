# Beta Tester Guide

## What To Test

- Register and log in.
- Complete onboarding.
- Upload a safe sample resume.
- Run resume analysis.
- Review job matches.
- Tailor a resume.
- Generate an application kit.
- Track an application.
- Generate interview prep.
- Export data from privacy settings.
- Submit feedback from the in-app feedback page.

## What To Report

- Confusing screens.
- Broken buttons or failed API calls.
- Incorrect or unhelpful AI output.
- Slow pages.
- Mobile layout problems.
- Privacy or trust concerns.

## What Not To Share

- Real passwords.
- Private API keys.
- Sensitive personal documents.
- Real recruiter conversations unless anonymized.

## Feedback Format

- What were you trying to do?
- What happened?
- What did you expect?
- How important is it from 1 to 5?
- Which page or workflow were you using?
