# v2 API Roadmap

- `POST /api/resumes/:id/ats-v2`
- `POST /api/resumes/:id/export`

## Jobs

- `POST /api/jobs/import/manual`
- `POST /api/jobs/import/csv`
- `POST /api/jobs/normalize`
- `GET /api/jobs/duplicates`

## Applications

- `GET /api/applications/:id/timeline`
- `POST /api/applications/:id/timeline`
- `GET /api/applications/follow-ups/due`

## Privacy

- `DELETE /api/privacy/account`

## Billing

## Admin

- `GET /api/admin/risk-signals`
