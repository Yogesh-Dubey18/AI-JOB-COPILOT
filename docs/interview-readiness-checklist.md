# Interview Readiness Checklist

Use before every HR or technical interview.

## Profile

- Resume version matches the role.
- LinkedIn and GitHub are updated.
- Portfolio/project links work.
- Introduction is practiced.

## Technical

- Can explain AI Job Copilot architecture.
- Can explain frontend pages and component structure.
- Can explain backend routes, models, services, and auth.
- Can explain MongoDB/Mongoose use.
- Can explain AI mock/provider fallback.
- Can explain testing and deployment readiness.

## Role-Specific

- React: components, hooks, forms, state, API calls.
- Node: Express routes, middleware, validation, errors.
- MongoDB: schemas, indexes, relationships.
- Java: OOP, collections, DSA basics.

## HR

- Why this role.
- Why this company.
- Strengths and weaknesses.
- Salary expectation.
- Availability.
- Questions to ask interviewer.
