# Live Demo Failure Handling Guide

## If Frontend Fails

- Open README and screenshots/docs.
- Explain architecture and demo flow.
- Show local build/test results.
- Show key files.

## If Backend Fails

- Open backend health docs.
- Explain API routes and tests.
- Show mock fallback behavior.
- Show Supertest test coverage.

## If AI Provider Is Missing

- Explain provider-ready architecture.
- Show mock fallback.
- Explain why secrets are not committed.

## If Live URL Is Missing

- Say deployment is pending platform credentials.
- Do not invent a URL.
- Show deployment runbooks.
