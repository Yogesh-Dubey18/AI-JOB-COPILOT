# Assignment Submission Template

Use this when submitting take-home assignments or project tasks.

## Email Template

Subject: Assignment Submission - [Role] - [Your Name]

Hi [Name],

Thank you for the opportunity to complete the assignment for the [Role] position. I have submitted the project here:

- GitHub repository: [Link]
- Live demo: [Link if available]
- Setup instructions: included in README

I focused on clean implementation, readable structure, responsive UI, validation, and clear documentation. Please let me know if you need any additional details.

Regards,  
[Your Name]

## README Checklist

- Project overview.
- Setup commands.
- Environment variables.
- Feature list.
- Technical decisions.
- Known limitations.
- Screenshots or demo link when available.

## Safety Rules

- Do not send private keys or credentials.
- Do not overbuild beyond the assignment scope.
- Do not use paid services unless explicitly agreed.
- Keep the repository clean and professional.
