# Monthly Project Roadmap

This plan converts long-term learning into small project improvements.

| Month | Project Focus | Output |
| --- | --- | --- |
| 1 | Repo confidence | Fresh-clone setup, clean README, local build/test confidence. |
| 2 | Resume workflow | Better upload, analysis, preview, fallback states, and tests. |
| 3 | Job workflow | Better job filters, match explanation, saved jobs, and trust indicators. |
| 4 | Application CRM | Timeline, follow-up reminders, rejection learning, and analytics improvements. |
| 5 | Interview coach | Mock interview flow, scoring clarity, prep plans, and answer history. |
| 6 | Deployment | Production env docs, health checks, CORS validation, live smoke checklist. |
| 7 | AI quality | Provider abstraction, schema checks, prompt versioning, usage tracking. |
| 8 | SaaS readiness | Plan limits, billing mock, admin controls, and safe upgrade prompts. |
| 9 | Privacy | Data export, delete account, privacy settings, and AI data handling notes. |
| 10 | Portfolio | Public portfolio generator, privacy controls, themes, and export options. |
| 11 | Extension/PWA | Browser assistant foundation, mobile UX, and offline fallback. |
| 12 | Stabilization | v2 beta test, bug tracker, release notes, and case study. |

## Monthly Review Questions

- What user problem became easier this month?
- What code changed, and how was it verified?
- What limitation remains?
- What can be shown in a recruiter demo without overclaiming?
