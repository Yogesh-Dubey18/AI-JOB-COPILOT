# Final Job Application Launch Plan

## Week 1

- Finalize master resume.
- Create role-wise resume versions.
- Update LinkedIn and GitHub profile.
- Prepare portfolio project section.
- Apply to 25 quality roles.
- Send 20 recruiter messages.
- Request 10 referrals.

## Week 2

- Review response rate.
- Improve weakest resume version.
- Practice interview questions.
- Apply to 25 more roles.
- Follow up on Week 1 applications.

## Daily Minimum

- 5 quality applications.
- 3 recruiter/referral messages.
- 1 interview practice block.
- 1 tracker update.

## Rule

Quality beats volume. Do not apply to unsafe jobs or roles that require fake experience.
