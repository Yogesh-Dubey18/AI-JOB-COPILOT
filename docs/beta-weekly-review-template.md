## 📋 Weekly Checklist

- [ ] **1. Metrics Telemetry Update:**
  - Run database analytics queries.
  - Update the [Beta Metrics Tracker](beta-metrics-tracker.md) table.
  - Compare results against targets in [Beta Success Metrics](beta-success-metrics.md).

- [ ] **2. Triage Board Sync:**
  - Review all active cards on [Triage Board](beta-feedback-triage-board.md).
  - Move fixed cards to the "Closed" column.
  - Re-prioritize "New" feedback cards into bugs, UX issues, or feature requests.

- [ ] **3. Hotfix Release Cycle:**
  - Package resolved bugs into a minor patch release (e.g., `v2.0.1-beta`).
  - Run the full verification checks locally before pushing.
  - Write patch release notes in `docs/releases/v2-beta-patch-notes.md`.

- [ ] **4. Onboarding Cohort Plan:**
  - Review the active status in the [Outreach Tracker](beta-tester-outreach-list-template.md).
  - Select 3–5 new testers to invite for the upcoming week.
  - Send the invite templates.
