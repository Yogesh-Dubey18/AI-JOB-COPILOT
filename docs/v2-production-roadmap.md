# v2 Production Roadmap

## Goal

Move AI Job Copilot from portfolio-ready demo to a stronger production architecture while keeping user safety, honest claims, and manual review at the center.

## v2 Themes

- Better resume parsing and ATS intelligence.
- Safer job-source normalization.
- Smarter application CRM.
- Stronger notifications and reminders.
- Higher quality AI copilot outputs.
- Plan-based usage limits.
- Admin operations and audit logs.
- Security, privacy, testing, CI/CD, observability, accessibility, and performance upgrades.

## Milestones

1. Resume intelligence upgrade.
2. Job source normalization.
3. Application tracker intelligence.
4. Notification/email/calendar foundation.
5. AI provider quality and guardrails.
6. Billing and usage limits.
7. Admin operations and audit logs.
8. Security and auth hardening.
9. E2E and CI/CD.
10. v2 beta and stable release.
