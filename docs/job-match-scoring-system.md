# Job Match Scoring System

Score jobs before applying.

| Factor | Weight | Notes |
| --- | --- | --- |
| Skills match | 40 | Actual skills only |
| Project fit | 20 | Can explain related project |
| Experience fit | 15 | Fresher/junior realistic |
| Location fit | 10 | Remote/hybrid/onsite acceptable |
| Salary fit | 5 | Realistic range |
| Keyword match | 10 | Resume can truthfully match |

## Recommendation

- 80 to 100: apply and tailor resume.
- 60 to 79: apply if role is realistic.
- 40 to 59: save only if learning value is high.
- Below 40: skip.
