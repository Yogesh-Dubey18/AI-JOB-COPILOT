# Database Schema

All models use Mongoose timestamps.

Models: User, Profile, Resume, ResumeAnalysis, ResumeVersion, Job, JobMatch, TailoredResume, ApplicationKit, Application, Interview, MockInterview, LearningPlan, Portfolio, JobScamReport, ChatSession, Notification, AnalyticsSnapshot, AIRequest, Feedback.

Key indexes include user ownership fields, job search text indexes, application status, profile user uniqueness, and AI request feature tracking.
