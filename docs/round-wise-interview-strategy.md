# Round-Wise Interview Strategy

## HR Call

- Clear intro.
- Role interest.
- Availability and salary expectation.
- Honest project summary.

## Technical Round

- Explain thought process.
- Use project examples.
- Admit gaps honestly.
- Ask clarifying questions.

## Assignment Round

- Confirm requirements.
- Prioritize working core flow.
- Document setup.
- Submit before deadline.

## Managerial Round

- Show learning mindset.
- Explain ownership.
- Discuss collaboration and feedback.

## Final HR

- Clarify offer details.
- Ask joining process.
- Stay professional and concise.
