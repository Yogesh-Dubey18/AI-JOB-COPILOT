# Long-Term DSA Plan

The goal is interview readiness, not endless problem collecting.

## Weekly Rhythm

- 3 days: solve new problems.
- 1 day: revise old mistakes.
- 1 day: timed mixed practice.
- 1 day: explain solutions aloud.
- 1 day: light review or rest.

## Topic Order

1. Arrays and strings.
2. Hash maps and sets.
3. Two pointers and sliding window.
4. Stack and queue.
5. Linked list.
6. Recursion and backtracking basics.
7. Trees and binary search trees.
8. Binary search.
9. Heaps and priority queues.
10. Graph basics.
11. Dynamic programming basics.

## Interview Explanation Checklist

- State brute force first.
- Explain optimized idea.
- Discuss time and space complexity.
- Mention edge cases.
- Walk through one example.
- Write clean code with meaningful names.
