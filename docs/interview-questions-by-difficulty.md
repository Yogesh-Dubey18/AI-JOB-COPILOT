# Interview Questions By Difficulty

## Easy

- Tell me about yourself.
- What is React?
- What is Node.js?
- What is MongoDB?
- What is an API?

## Medium

- Explain JWT auth.
- Explain `useEffect`.
- Explain middleware.
- Explain indexes.
- Explain your project architecture.

## Hard

- How would you scale job matching?
- How would you secure resume uploads?
- How would you add real AI providers safely?
- How would you design application follow-up reminders?
