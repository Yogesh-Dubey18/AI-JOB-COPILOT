# User Analytics Review

Use analytics to improve user outcomes, not to inflate vanity metrics.

## Weekly Product Questions

- Do users finish onboarding?
- Do users upload resumes?
- Do users run resume analysis?
- Do users save or apply to jobs?
- Do users update application statuses?
- Do users return for interview prep?

## Funnel

1. Visit.
2. Register.
3. Complete onboarding.
4. Upload resume.
5. Analyze resume.
6. View matched jobs.
7. Create application kit.
8. Track application.
9. Prepare for interview.

## Quality Metrics

- Resume score improvement.
- Application response rate.
- Interview rate.
- Offer rate.
- Most missing skills.
- Most used AI features.

## Privacy Rules

- Aggregate metrics where possible.
- Avoid exposing user resume content in admin views.
- Do not sell or share user job-search data.
