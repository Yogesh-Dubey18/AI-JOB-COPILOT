## Tag version: `v2.0.0-beta`
## Release title: `AI Job Copilot v2 Beta Release`

We are excited to announce the launch of **AI Job Copilot v2.0.0-beta**! This release upgrades the platform into a realistic, production-ready, career operating cockpit for job seekers.

### 🌟 What's New
- **Guided Workflow (`/guided-workflow`):** 7-step connected job-search assistant.
- **Recruiter CRM (`/contacts`):** Track network contacts, companies, notes, and LinkedIn URLs.
- **Provider Status UI (`/settings/integrations`):** Real-time readiness of external integrations.
- **Resilient Mock Auth:** Safe bypass "Continue in Demo Mode" option on login if backend is unreachable.
- **Job Filters:** Added experience levels, remote types, and salary filtering.
