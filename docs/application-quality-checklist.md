# Application Quality Checklist

Run this checklist before submitting any application.

## Role Fit

- The title matches one of the target roles.
- Experience requirement is realistic.
- Required skills overlap with actual skills and projects.
- Location, remote policy, and salary range are acceptable.

## Resume Fit

- Resume headline matches the role.
- Skills section contains only true skills.
- Project bullets show relevant technology and impact.
- Resume is ATS-friendly and easy to scan.
- File name is professional.

## Message Fit

- Cover letter or HR email names the company and role.
- Message is concise and not generic.
- No fake experience or exaggerated claims.
- Links work and point to relevant projects.

## Safety

- Official apply link is verified.
- No payment or fee is requested.
- Recruiter identity looks credible.
- Company domain and job details match.

## Tracker

- Application is logged immediately.
- Resume version is recorded.
- Follow-up date is set.
