# First Interview Sprint Plan

## Goal

Prepare for the first shortlist or interview with a focused 7-day sprint.

## Daily Plan

| Day | Focus | Output |
| --- | --- | --- |
| 1 | Resume and intro | 60-second intro |
| 2 | Project deep dive | AI Job Copilot explanation |
| 3 | React/Frontend | Component and hooks review |
| 4 | Backend/API | Express, JWT, MongoDB |
| 5 | DSA basics | Arrays, strings, hashing |
| 6 | Mock interview | Record weak areas |
| 7 | Company-specific prep | Final notes and questions |

## Minimum Practice

- One project explanation daily.
- Three coding problems.
- One HR answer review.
- One mock interview.
