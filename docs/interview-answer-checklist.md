# Interview Answer Checklist

Before answering:

- Listen fully.
- Clarify if needed.
- Keep the answer structured.
- Use one real example.
- Avoid fake claims.

## Technical Answer Structure

1. Definition.
2. Why it matters.
3. Example from project.
4. Tradeoff or limitation.

## Project Answer Structure

1. Problem.
2. Features.
3. Tech stack.
4. Your contribution.
5. Challenge.
6. Improvement plan.

## HR Answer Structure

1. Direct answer.
2. Supporting example.
3. Fit for the role.
