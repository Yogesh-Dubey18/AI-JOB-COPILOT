# Resume Version Strategy

Use a small number of strong resume versions instead of endless random edits.

## Core Versions

- Base resume: complete truthful profile.
- React resume: frontend-first version.
- MERN resume: full-stack version.
- Node backend resume: backend/API-first version.
- Java resume: Java/OOP/DSA-focused version.

## Job-Specific Versions

Create a job-specific version only when:

- The job is high match.
- The company is trustworthy.
- The role is realistic.
- The customization can be truthful.

## Naming

- `base-full-stack`
- `react-developer-v1`
- `mern-developer-v1`
- `node-backend-v1`
- `java-developer-v1`
- `company-role-YYYY-MM-DD`

## Performance Review

Track:

- Applications per version.
- Replies per version.
- Interviews per version.
- Missing keywords.
- Rejection patterns.
