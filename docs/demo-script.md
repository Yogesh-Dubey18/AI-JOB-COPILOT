# Demo Script

Use this 5 to 7 minute flow for recruiters or portfolio reviewers.

## Opening

AI Job Copilot is a job-seeker focused AI SaaS platform. It helps a candidate upload one resume, understand ATS gaps, find matching jobs, tailor application materials, track applications, prepare for interviews, and improve after rejection.

It is not a job board for employers and it does not auto-apply.

## Flow

1. Show the landing page and positioning.
2. Register or log in.
3. Open dashboard and explain the job-search operating system layout.
4. Complete or preview onboarding.
5. Upload a sample resume.
6. Run resume analysis and explain ATS score sections.
7. Open jobs and show match/trust signals.
8. Open a job detail page and explain fit, missing skills, and readiness.
9. Tailor resume for the job.
10. Generate cover letter, HR email, LinkedIn, WhatsApp, and referral messages.
11. Add the job to the application tracker.
12. Generate interview prep or run mock interview.
13. Open analytics and explain conversion tracking.
14. Open admin dashboard and explain operations architecture.

## Technical Talking Points

- Next.js App Router frontend with TypeScript and Tailwind.
- Express TypeScript backend.
- MongoDB/Mongoose models with in-memory fallback for local demos.
- JWT auth with refresh-token cookie architecture.
- AI provider abstraction for mock, Gemini, and OpenAI.
- Safe user-review rule for all generated content.
- Deployment-ready docs for Vercel, backend host, and MongoDB Atlas.

## Honest Limitations

- Billing is mock/Stripe-ready.
- Email sending is mock unless SMTP env values are configured.
- AI uses structured fallback when provider keys are missing.
- Live URLs must be added only after real deployment.
