# Interview Master Plan

This plan prepares for fresher and entry-level full-stack interviews.

## Weekly Rhythm

- 3 technical revision sessions.
- 2 coding practice sessions.
- 2 project explanation rehearsals.
- 1 mock interview.
- 1 HR answer review.

## Core Tracks

- Resume and project deep dive.
- JavaScript and React.
- Node.js and Express APIs.
- MongoDB and database basics.
- DSA fundamentals.
- System design basics for freshers.
- HR and communication practice.

## Interview Readiness Score

Rate each from 1 to 10:

- Project clarity.
- JavaScript basics.
- React basics.
- Backend/API basics.
- Database basics.
- DSA basics.
- HR confidence.
- Communication.
