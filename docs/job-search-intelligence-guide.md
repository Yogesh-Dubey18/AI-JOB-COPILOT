# Job Search Intelligence Guide

Job Search Intelligence helps the user answer: "What should I improve this week to get better job-search outcomes?"

## Core Signals

### Profile Completeness

Low score means the user should complete role, skills, location, links, and career target fields before expecting good matches.

### Resume Readiness

Uses the latest saved resume ATS score. If no analysis exists, the score intentionally starts low so the dashboard asks the user to analyze a resume.

### Application Velocity

Measures recent application activity against a weekly target of 10 focused, reviewed applications. This is a process metric, not a quota that should encourage spam.

### Follow-Up Hygiene

Looks at overdue follow-ups and stale active applications. This supports manual, user-reviewed follow-up only.

### Interview Conversion

Compares tracked applications with interview-stage outcomes. Low conversion can mean targeting, resume fit, project explanation, or missing referral signals need work.

### Skill Focus

Aggregates missing skills from job matches and resume analyses. It is used to suggest learning priorities, not to add fake resume claims.

## Health Levels

| Score | Level |
| --- | --- |
| 80-100 | Strong |
| 60-79 | Improving |
| 40-59 | Needs focus |
| 0-39 | At risk |

## Recommended Weekly Workflow

1. Check health score every Monday.
2. Review top missing skills.
3. Tailor one resume version for the best target role.
4. Apply to 5 to 10 high-match roles.
5. Track every application status and source.
6. Send manual follow-ups when due.
7. Review response/interview rate at the end of the week.

## Risk Flags

The system can flag:

- High rejection rate.
- Stale applications.
- Missing resume analysis.
- No tracked applications.

These flags are meant to guide process improvement, not discourage the user.

## Manual Review Rules

- Do not auto-apply.
- Do not auto-send follow-ups.
- Do not scrape protected job sites.
- Do not add skills or experience that the user cannot honestly support.
- Do not claim health score is a hiring guarantee.

## Product Extensions

Future issue-based upgrades can add:

- Weekly analytics digest.
- Resume version performance tracking.
- Job source ROI dashboard.
- Interview conversion trend.
- Privacy-safe portfolio visit analytics.
