# Final Manual Actions

## Required Before Live Demo

- Create MongoDB Atlas database.
- Deploy backend to Render/Railway/Fly.
- Deploy frontend to Vercel.
- Set environment variables in dashboards.
- Configure `NEXT_PUBLIC_API_URL`.
- Configure backend CORS for frontend URL.
- Verify backend health.
- Run production smoke test.

## Optional Before Commercial Use

- Configure real AI provider.
- Configure email provider.
- Configure billing provider.
- Configure monitoring/error tracking.
- Add legal review for privacy, terms, refund, and AI disclaimers.
- Add support process.

## Never Commit

- Real `.env`.
- API keys.
- MongoDB URI.
- JWT secrets.
- Stripe keys.
- Email credentials.
