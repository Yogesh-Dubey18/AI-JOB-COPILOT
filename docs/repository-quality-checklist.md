# Repository Quality Checklist

## Safety

- `.env.example` files are placeholder-only.
- Real `.env` files are ignored.
- Build output is ignored.
- Uploads, exports, generated PDFs, reports, and credentials are ignored.
- Git safety check passes.

## Code

- TypeScript builds pass.
- Backend API tests pass.
- Frontend render tests pass.
- Shared types build.
- Scripts use npm consistently.

## Docs

- README explains honest scope.
- Deployment guide has placeholders, not fake live URLs.
- Docs index links major documents.
- Changelog exists.
- Documentation link check passes.

## Product

- User-reviewed application content only.
- No auto-apply.
- No unsafe scraping.
- Mock/provider-ready integrations are labeled.
- Known limitations are documented.
