# Feedback Collection Plan

This document outlines how we collect, parse, and triage beta feedback for the **AI Job Copilot** platform.

---

## 📥 Channels

1. **In-App Feedback Form:** Users submit comments via `/feedback`.
2. **GitHub Issues:** Users log bugs and feature requests directly in the repo.
3. **Outreach Surveys:** Direct email follow-ups with active testers.

---

## 🔄 Triage Flow

1. **Intake:** Every feedback item is recorded in the triage board: [beta-feedback-triage-board.md](beta-feedback-triage-board.md).
2. **Classification:**
   - **Bug:** Visual or functional regressions.
   - **UX Gap:** Confusion on limits or navigation.
   - **Feature Request:** Future enhancements.
3. **Prioritization:** Assigned severity levels (Critical, High, Medium, Low).
4. **Resolution:** Bugs are assigned, patched, verified, and closed.
